# IPL Analytics Dashboard 🏏📊

## Overview
The IPL Analytics Dashboard is an interactive Power BI project developed to analyze Indian Premier League (IPL) data and provide insights into team performance, player statistics, match results, and tournament trends.

This dashboard helps cricket fans, analysts, and sports enthusiasts explore IPL data through interactive visualizations and performance metrics.

---

## Features
- 🏏 Team Performance Analysis
- 👤 Player Statistics Dashboard
- 📈 Match Win Analysis
- 🎯 Top Run Scorers & Wicket Takers
- 🏆 Season-wise IPL Insights
- 🌍 Venue-wise Match Analysis
- 📊 Interactive Charts and Filters
- 📅 Tournament Trend Analysis

---

## Tools & Technologies Used
- Power BI
- Microsoft Excel / CSV Dataset
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation

---

## Dashboard Insights
The dashboard provides:
- Total Matches Played
- Team Winning Statistics
- Top Performing Players
- Highest Run Scorers
- Most Wickets Taken
- Toss Decision Analysis
- Venue-wise Match Results
- Season-wise Team Performance

---

## Key Observations
- Teams with strong batting lineups performed consistently well.
- Toss decisions had a noticeable impact on match outcomes.
- Certain venues favored high-scoring matches.
- Top players maintained consistent performance across seasons.
- Match trends and win ratios varied significantly between teams.
